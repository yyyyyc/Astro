# לוגיקת הפרויקט

אפליקציית Flask שמחשבת מיקומי ירח אסטרולוגיים בכמה שיטות תזמון, ולכל תוצאה שולפת
טקסט תחזית מתאים בעברית ממסד נתונים ב-Supabase ‏(PostgreSQL).

האפליקציה מציעה ארבע יכולות:

| יכולת | עמוד | השאלה שהיא עונה עליה |
|---|---|---|
| Tertiary I ‏(טרשיארי I) | `/` | היכן נמצא היום הירח המתקדם בשיטת Tertiary I? |
| Tertiary II ‏(Minor) | `/` | היכן נמצא היום הירח המתקדם בשיטת הפרוגרסיה המינורית? |
| Moon of Transit ‏(ירח בטרנזיט) | `/moon-transit` | באיזה מזל נמצא הירח האמיתי עכשיו, ומתי ייכנס לכל אחד מהמזלות הבאים? |
| Secondary Progression ‏(פרוגרסיה סקנדרית) | `/secondary-progression` | היכן נמצא היום הירח המתקדם בשיטת יום-לשנה? |

כל לוגיקת החישוב נמצאת ב-`app.py`. כל עמוד הוא תבנית יחידה ועצמאית בתיקייה `templates/`.

---

## 1. ליבת החישוב האסטרונומי המשותפת

כל המיקומים מחושבים בעזרת הספרייה **`ephem`**.

- **גלגל המזלות:** טרופי, כלומר אורך אקליפטי שנמדד ביחס לנקודת השוויון של אותו תאריך
  (`ephem.Ecliptic(body, epoch=date)`).
- **נקודת מבט:** גאוצנטרית. המיקום משמש **רק לקביעת אזור הזמן**, ואינו משנה את המיקומים.
- **גוף שמימי:** רק הירח (`PLANETS = {"Moon": ephem.Moon}`), ובנוסף השמש לחישוב מזל השמש.

| פונקציה | תפקיד |
|---|---|
| `ecliptic_longitude(planet_class, ephem_date)` | האורך הטרופי של הגוף, 0–360°. |
| `longitude_to_zodiac(lon)` | אורך ← `(sign, degrees, minutes, seconds)`. המזל = `int(lon / 30)`; המעלה בתוך המזל = `lon % 30`. |
| `resolve_timezone(lat, lon)` | קואורדינטות ← אזור זמן של `pytz`, בעזרת `TimezoneFinder`. |
| `localize(tz, naive_dt)` | שעון מקומי ← זמן עם אזור זמן. בשעה כפולה (חזרה משעון קיץ) נבחרת שעון חורף; בשעה שדולגה (מעבר לשעון קיץ) הזמן מוזז שעה קדימה. |
| `sun_sign_on(date)` | מזל השמש הלידתי לפי תאריך לידה, נלקח בשעה 12:00 UTC כי שעת הלידה לא ידועה. ביום שבו השמש מחליפה מזל ייתכן שיתקבל המזל הסמוך. |

**קבועים**

- `SIDEREAL_MONTH_DAYS = 27.321661`: חודש סידרי אחד (הקפת הירח ביחס לכוכבים).
- `TROPICAL_YEAR_DAYS = 365.242190`: שנה טרופית אחת.

**המעלה שמשמשת לתחזיות:** התחזיות נשלפות לפי **המעלה השלמה** (0–29), בחיתוך ולא בעיגול.
לדוגמה, ‏13°41′ בקשת משתמש במעלה 13.

## 2. פרוגרסיות טרשיאריות (העמוד הראשי `/`)

**קלט:** תאריך לידה, שעת לידה (מקומית), מקום לידה ותאריך פרוגרסיה.
- שעת הפרוגרסיה קבועה ל-12:00 בשעון המקומי.
- שני התאריכים מוגדרים כברירת מחדל להיום; המקום מוגדר כברירת מחדל למיקום הנוכחי של הדפדפן.

**החישוב** (`POST /calculate`):

1. רגע הלידה ורגע הפרוגרסיה מומרים ל-UTC לפי אזור הזמן של מקום הלידה.
2. `elapsed_days` = פרוגרסיה − לידה; הערך אינו יכול להיות שלילי.
3. **Tertiary I:** יום אחד אחרי הלידה = חודש סידרי אחד של חיים.

</div>

```
progressed = birth + elapsed_days / 27.321661 days
```

<div dir="rtl">

4. **Tertiary II (פרוגרסיה מינורית):** חודש סידרי אחד אחרי הלידה = שנה אחת של חיים.

</div>

```
progressed = birth + (elapsed_days / 365.24219) × 27.321661 days
```

<div dir="rtl">

5. לכל רגע מתקדם מחושבים המזל, המעלה, הדקות, השניות והאורך של הירח.

**הפלט:** סיכום (אזור זמן, הפרש מ-UTC בזמן הלידה, זמן הלידה המקומי וב-UTC, ימים שחלפו), ואחריו
טבלה לכל שיטה עם תאריך המפה המתקדמת ומיקום הירח.

**תחזיות:** לחיצה על שורת הירח טוענת את הטקסט שלה לפי **מזל + מעלה שלמה**:

| שיטה | נתיב | טבלאות |
|---|---|---|
| Tertiary I | `GET /forecast/tertiary1?sign=&degree=` | `tbl_tertiary1_forecasts` ← `tbl_tertiary1_forecasts_texts` |
| Tertiary II | `GET /forecast/tertiary2?sign=&degree=` | `tbl_tertiary2_forecasts` ← `tbl_tertiary2_forecasts_texts` (מחזיר גם את ערך `tertiary`) |

## 3. ירח בטרנזיט (`/moon-transit`)

המזל הנוכחי של הירח האמיתי (בטרנזיט), והזמנים שבהם הוא נכנס לכל מזל ויוצא ממנו.

**קלט:**
- **מיקום:** ברירת המחדל היא המיקום הנוכחי של הדפדפן; אפשר גם לחפש מקום.
- **תאריך ושעה:** ברירת המחדל היא עכשיו.
- **תאריך לידה:** אופציונלי; העמוד ממלא מראש את התאריך של לפני 30 שנה מהיום.

**השיטות המרכזיות:**
- `moon_of_transit(lat, lon, local_dt)` מחזירה את המזל הנוכחי של הירח ואת **תחילת** ו**סוף**
  שהותו בו, באזור הזמן של המיקום.
- `moon_sign_boundary()` מוצאת כל מעבר מזל:
  - היא מתקדמת קדימה או אחורה בצעדים של 3 שעות. הירח נע לכל היותר כ-15.4° ביום, כך שצעד אחד
    מכסה פחות מ-2° ולעולם לא ידלג על מזל של 30°.
  - לאחר מכן היא חוצה את הצעד האחרון שוב ושוב עד לדיוק של שנייה אחת.
- `moon_transit_table()` מחזירה את המזל הנוכחי ועוד 11 המזלות הבאים, מחזור מלא של כ-27 ימים.
  סוף כל מזל הוא תחילת המזל הבא.

**טבלת הפלט:** שורה לכל מזל עם התחלה, סוף ומשך (בשעות, לרוב 50–60). הזמנים מקומיים
ושינויי שעון קיץ נלקחים בחשבון. המזל הנוכחי מודגש.

**בית (רק כשהוזן תאריך לידה):** הבתים נספרים מ**מזל השמש** הלידתי (בתים של מזל שלם):

</div>

```
house = (moon_sign_index − sun_sign_index) mod 12 + 1
```

<div dir="rtl">

לדוגמה, כשהשמש בטלה והירח בבתולה, הירח נמצא בבית ה-6.

**תחזית (כפתור Forecast בכל שורה, דורש תאריך לידה):**

- ערך `forecast_group` נקבע לפי התאריך והשעה שנבחרו ונקודת האמצע של תקופת המזל באותה שורה:
  - לפני נקודת האמצע ← **1** (המחצית הראשונה)
  - בנקודת האמצע או אחריה ← **2** (המחצית השנייה)
- כל שורה שאחרי השורה הנוכחית מתחילה אחרי הזמן שנבחר, ולכן השורות האלה תמיד מקבלות קבוצה 1.
- שליפה: `GET /forecast/moon-transit?house=&group=`, מתוך `tbl_moon_of_transit_daily_forecasts`
  (`moon_location` = הבית, `forecast_group` = המחצית) בצירוף `tbl_moon_of_transit_daily_forecasts_texts`.

## 4. פרוגרסיה סקנדרית (`/secondary-progression`)

**קלט:** אותו טופס כמו בעמוד הראשי: תאריך, שעה ומקום לידה, ותאריך פרוגרסיה
(שעת הפרוגרסיה קבועה ל-12:00).

**השיטה** `secondary_progression(lat, lon, birth_dt, target_dt)`: יום-לשנה, כלומר יום אחד אחרי
הלידה = שנה אחת של חיים.

</div>

```
age_years  = (target − birth) / 365.24219 days
progressed = birth + age_years days
```

<div dir="rtl">

השיטה מחזירה את המזל, המעלה, הדקות, השניות והאורך של הירח המתקדם, וכן את הגיל ואת תאריך
המפה המתקדמת. הירח המתקדם נע כ-12–15° בשנה, כמעלה אחת בחודש.

**תחזית:** נטענת אוטומטית אחרי כל חישוב, לפי **מזל + מעלה שלמה**:
`GET /forecast/secondary?sign=&degree=`, מתוך `tbl_secondary_progression_forecasts` בצירוף
`tbl_secondary_progression_forecasts_texts`. במסד הנתונים יש שורה אחת לכל מזל ומעלה
(360 שורות, שחולקות 27 טקסטים).

## 6. גישה למסד הנתונים

- מחרוזת החיבור נלקחת ממשתנה הסביבה `ASTRO_DB_URL` (נטען מקובץ `.env`),
  ומשמשת דרך SQLAlchemy ו-psycopg. אם היא חסרה, נתיבי התחזית מחזירים שגיאה.
- כל שאילתות התחזית הן שליפות `SELECT … JOIN …_texts` עם פרמטרים. האפליקציה לעולם אינה כותבת למסד הנתונים.
- מזהי המזלות הם 1–12 לפי סדר המזלות (טלה = 1 … דגים = 12), בהתאם ל-`tbl_signs`.
- טקסטי התחזית כתובים בעברית ומוצגים מימין לשמאל (`dir="auto"`).
- הגדרות הטבלאות והעמודות: ראו `docs/database-schema.md`.

## 7. מוסכמות ומגבלות

- **הזנת תאריכים:** התאריכים מוקלדים בפורמט `dd/mm/yyyy` ונשלחים לשרת בפורמט `YYYY-MM-DD`.
  התצוגה מהשרת היא בפורמט `dd/mm/yyyy HH:MM`.
- **אזורי זמן:** כל חישוב משתמש באזור הזמן של המיקום שהוזן: מקום הלידה בפרוגרסיות,
  והמיקום שנבחר בירח בטרנזיט.
- **ימי מעבר מזל:** מזל השמש לפי תאריך לידה מחושב בצהרי UTC, ולכן מי שנולד ביום שבו השמש
  מחליפה מזל עשוי לקבל את המזל הסמוך.
- **זמני הירח בטרנזיט:** הם גאוצנטריים. תיקון לפי מיקום הצופה על פני כדור הארץ היה יכול להזיז
  את מעברי המזל בעד כשעתיים; התיקון הזה לא מיושם במכוון.

## 8. ניהול גרסאות

- הקובץ `version.json` מכיל `{version, datetime}`. העמוד הראשי מציג אותו בפינה הימנית העליונה בפורמט
  `vX.Y.Z · dd/mm/yyyy HH:MM`.
- הפקודה `python bump_version.py [patch|minor|major]` מעלה את מספר הגרסה ורושמת את השעה הנוכחית.
- **כלל:** יש להעלות את הגרסה לפני כל `git push` ולכלול את `version.json` ב-commit יחד עם השינוי.
